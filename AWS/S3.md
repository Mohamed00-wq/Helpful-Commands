## 1. Basic Commands (single bucket)

```bash
# Create a bucket
aws s3 mb s3://my-first-bucket --region us-east-1

# List all buckets
aws s3 ls

# List contents of a specific bucket
aws s3 ls s3://my-first-bucket

# Upload a file
aws s3 cp file.txt s3://my-first-bucket/

# Upload a whole folder (recursive)
aws s3 cp ./my-folder s3://my-first-bucket/my-folder --recursive

# Download a file
aws s3 cp s3://my-first-bucket/file.txt ./

# Sync a folder (most used command in practice)
aws s3 sync ./local-folder s3://my-first-bucket/folder

# Delete a file
aws s3 rm s3://my-first-bucket/file.txt

# Delete an empty bucket
aws s3 rb s3://my-first-bucket
```

## 2. Working with Multiple Buckets (intermediate)

```bash
# List all buckets with approximate sizes
for bucket in $(aws s3 ls | awk '{print $3}'); do
  echo "Bucket: $bucket"
  aws s3 ls s3://$bucket --summarize --human-readable --recursive | tail -2
done

# Copy from one bucket to another
aws s3 sync s3://source-bucket s3://destination-bucket

# Sync to multiple buckets in a loop
for bucket in bucket1 bucket2 bucket3; do
  aws s3 sync ./backup s3://$bucket/backup --exclude "*.tmp"
done

# Filter files (include/exclude)
aws s3 sync ./data s3://my-bucket \
  --exclude "*" \
  --include "*.jpg" \
  --include "*.png"

# Delete specific file types across a bucket
aws s3 rm s3://my-bucket --recursive --exclude "*" --include "*.log"
```

## 3. Using `s3api` (advanced — fine-grained control)

```bash
# List all buckets as JSON with more detail
aws s3api list-buckets --query 'Buckets[*].[Name,CreationDate]' --output table

# Check the region of each bucket
for bucket in $(aws s3api list-buckets --query 'Buckets[].Name' --output text); do
  region=$(aws s3api get-bucket-location --bucket $bucket --query 'LocationConstraint' --output text)
  echo "$bucket -> $region"
done

# Enable versioning on a bucket
aws s3api put-bucket-versioning \
  --bucket my-bucket \
  --versioning-configuration Status=Enabled

# Apply a setting to multiple buckets at once (e.g. block public access)
for bucket in $(aws s3api list-buckets --query 'Buckets[].Name' --output text); do
  aws s3api put-public-access-block \
    --bucket $bucket \
    --public-access-block-configuration \
    BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
done

# Add a lifecycle policy (e.g. auto-delete after 30 days)
aws s3api put-bucket-lifecycle-configuration \
  --bucket my-bucket \
  --lifecycle-configuration file://lifecycle.json
```

## 4. High Performance / Large Files (Advanced)

```bash
# Parallel uploads with tuned concurrency
aws configure set default.s3.max_concurrent_requests 20
aws configure set default.s3.multipart_threshold 64MB
aws configure set default.s3.multipart_chunksize 16MB

aws s3 cp bigfile.iso s3://my-bucket/ --storage-class STANDARD_IA

# Advanced filtering query
aws s3api list-objects-v2 --bucket my-bucket \
  --query 'Contents[?Size > `1000000`].[Key,Size]' --output table

# Get total bucket size via CloudWatch (more accurate than s3 ls)
aws cloudwatch get-metric-statistics \
  --namespace AWS/S3 \
  --metric-name BucketSizeBytes \
  --dimensions Name=BucketName,Value=my-bucket Name=StorageType,Value=StandardStorage \
  --start-time $(date -u -d '2 days ago' +%Y-%m-%dT%H:%M:%S) \
  --end-time $(date -u +%Y-%m-%dT%H:%M:%S) \
  --period 86400 --statistics Average
```

## Tip
`aws s3` (high-level) covers 90% of daily use (cp, sync, rm, ls). Use `aws s3api` when you need fine-grained control (versioning, policies, lifecycle, replication) — this is exactly what shows up in SAA-C03 automation and multi-bucket scenarios.
