## Bucket Operations

| Command | Description |
|---|---|
| `aws s3 mb s3://my-bucket --region us-east-1` | Create a new S3 bucket |
| `aws s3 rb s3://my-bucket` | Delete an empty bucket |
| `aws s3 rb s3://my-bucket --force` | Delete a bucket and all its contents |
| `aws s3api list-buckets --query "Buckets[].Name"` | List all bucket names |
| `aws s3api head-bucket --bucket my-bucket` | Check if a bucket exists |
| `aws s3api get-bucket-location --bucket my-bucket` | Get bucket region |
| `aws s3api get-bucket-versioning --bucket my-bucket` | Check versioning status |
| `aws s3api put-bucket-versioning --bucket my-bucket --versioning-configuration Status=Enabled` | Enable versioning |
| `aws s3api put-bucket-versioning --bucket my-bucket --versioning-configuration Status=Suspended` | Suspend versioning |
| `aws s3api get-bucket-encryption --bucket my-bucket` | Check default encryption |
| `aws s3api put-bucket-encryption --bucket my-bucket --server-side-encryption-configuration '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"aws:kms"}}]}'` | Set default KMS encryption |

```bash
# Bucket operations
aws s3 mb s3://my-bucket --region us-east-1
aws s3 rb s3://my-bucket --force
aws s3api list-buckets --query "Buckets[].Name"
aws s3api head-bucket --bucket my-bucket
aws s3api get-bucket-location --bucket my-bucket

# Versioning
aws s3api get-bucket-versioning --bucket my-bucket
aws s3api put-bucket-versioning \
  --bucket my-bucket \
  --versioning-configuration Status=Enabled

# Default encryption
aws s3api put-bucket-encryption \
  --bucket my-bucket \
  --server-side-encryption-configuration '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"aws:kms"}}]}'
```

## Object Operations

| Command | Description |
|---|---|
| `aws s3 ls s3://my-bucket` | List objects in a bucket |
| `aws s3 ls s3://my-bucket --recursive` | List all objects recursively |
| `aws s3 cp file.txt s3://my-bucket/` | Upload a file |
| `aws s3 cp s3://my-bucket/file.txt ./` | Download a file |
| `aws s3 mv file.txt s3://my-bucket/` | Move a file to S3 |
| `aws s3 mv s3://my-bucket/file.txt ./` | Move a file from S3 |
| `aws s3 rm s3://my-bucket/file.txt` | Delete an object |
| `aws s3 rm s3://my-bucket/ --recursive` | Delete all objects in a bucket |
| `aws s3 sync ./folder s3://my-bucket/folder` | Sync local folder to S3 |
| `aws s3 sync s3://my-bucket/folder ./folder` | Sync S3 to local folder |
| `aws s3 cp s3://my-bucket/file.txt ./ --sse aws:kms` | Download with KMS decryption |
| `aws s3api head-object --bucket my-bucket --key file.txt` | Get object metadata |
| `aws s3api get-object --bucket my-bucket --key file.txt ./file.txt` | Download with range |
| `aws s3api delete-object --bucket my-bucket --key file.txt` | Delete an object (API) |

```bash
# Upload / Download
aws s3 cp file.txt s3://my-bucket/
aws s3 cp s3://my-bucket/file.txt ./
aws s3 mv file.txt s3://my-bucket/
aws s3 rm s3://my-bucket/file.txt

# Sync
aws s3 sync ./folder s3://my-bucket/folder
aws s3 sync s3://my-bucket/folder ./folder

# Object details
aws s3api head-object --bucket my-bucket --key file.txt
```

## Presigned URLs

| Command | Description |
|---|---|
| `aws s3 presign s3://my-bucket/file.txt --expires-in 3600` | Generate a presigned URL (1 hour) |
| `aws s3 presign s3://my-bucket/file.txt --expires-in 604800` | Generate a presigned URL (7 days max) |

## Versioning & MFA Delete

| Command | Description |
|---|---|
| `aws s3api list-object-versions --bucket my-bucket` | List all object versions |
| `aws s3api list-object-versions --bucket my-bucket --prefix file.txt` | List versions of a specific object |
| `aws s3api delete-object --bucket my-bucket --key file.txt --version-id xxx` | Delete a specific version |
| `aws s3api delete-object --bucket my-bucket --key file.txt` | Delete latest version (add delete marker) |
| `aws s3api get-object-tagging --bucket my-bucket --key file.txt` | Get object tags |
| `aws s3api put-object-tagging --bucket my-bucket --key file.txt --tagging '{"TagSet":[{"Key":"env","Value":"prod"}]}'` | Tag an object |

```bash
# Versioning
aws s3api list-object-versions --bucket my-bucket
aws s3api delete-object --bucket my-bucket --key file.txt --version-id xxx

# Tags
aws s3api get-object-tagging --bucket my-bucket --key file.txt
aws s3api put-object-tagging \
  --bucket my-bucket --key file.txt \
  --tagging '{"TagSet":[{"Key":"env","Value":"prod"}]}'
```
